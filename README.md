# Public Cover Letter

This repository contains the public version of my general cover letter.

Private or application-specific information is omitted from this version.

## Structure

- `coverletter_sajib_mqu_public.tex` --- main cover-letter source
- `coverletter_sajib_mqu_public.pdf` --- compiled public cover letter

## Build

Compile with:

```bash
make
```

The cover letter is built with LuaLaTeX via `latexmk`.
